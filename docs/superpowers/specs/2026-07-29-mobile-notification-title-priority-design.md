# 移动端通知标题优先设计

## 目标

在窄屏移动端通知列表中隐藏每条通知的日期，让标题获得更多可用宽度；桌面端列表和通知详情继续显示完整时间。

## 范围

- 仅在移动端断点（`max-width: 640px`）隐藏 `.notif-time`。
- 不修改通知标题、`new` 标记、已读/删除按钮、详情页时间、数据接口或操作逻辑。
- 不改变桌面端通知列表布局。

## 交互与视觉

- 移动端列表行保留现有按钮和点击进入详情的行为。
- 日期在详情页始终可见，因此隐藏列表日期不会丢失时间信息。
- 释放的横向空间由标题的 `flex: 1` 自动获得；标题仍维持单行省略，避免增加列表高度。

## 验收

- `≤640px` 时 `.notif-time` 不占据布局空间，通知标题宽度显著增加。
- `>640px` 时日期仍可见。
- 通知详情日期仍可见。
- 通知操作与既有前端回归测试不受影响。
